# Brief — 작성기 엔진 비교 시험 (Tiptap vs TinyMCE)

> **범위**: 시험만. 같은 Material 툴바를 두 엔진에 붙인 시험 화면을 만들고, 메일 작성 흐름 한 바퀴로 비교해 **채택 엔진과
> 근거를 보고**한다. 제품 작성 창에는 넣지 않는다. 방향은 [DESIGN-MAIL-GUI.md](DESIGN-MAIL-GUI.md) "작성기 — 리치 텍스트
> 방향"(2026-11-26). 규칙은 [gui/AGENTS.md](../gui/AGENTS.md).

2026-11-26 작성. 보내는 첨부([BRIEF-MAIL-OUTGOING-ATTACHMENTS.md](BRIEF-MAIL-OUTGOING-ATTACHMENTS.md)) 뒤에 착수.

## 정해진 것 (DESIGN-MAIL-GUI "작성기")

```txt
역할        엔진 = 본문 편집만.  툴바는 Material 로 직접(엔진 UI 끔), 첨부·인라인 이미지 저장·업로드는 앱
인라인 이미지  편집 중 = 앱 내부 ID + 로컬 미리보기, 저장·발송 = blobId + cid: 파트.  엔진이 cid 를 지원할 필요 없음
첫 범위     굵게·기울임·밑줄·목록·링크·이미지 붙여넣기.  표·마크다운 원문 저장 없음
저장 형식   text/html + text/plain 대안.  엔진 내부 형식을 서버에 넣지 않음
후보        Tiptap(MIT) 1순위, TinyMCE 8(GPL-2.0-or-later — 클라이언트 라이선스와 맞음, 앱에 번들, Tiny Cloud·API 키 없음)
```

## 지시

1. **시험 화면**: 개발 빌드에서만 열리는 경로 하나(예: `/dev/editor-spike`, 배포 빌드에서 제외)에 두 엔진을 탭으로.
   툴바 컴포넌트 하나(Material — 굵게·기울임·밑줄·글머리·번호 목록·링크)를 두 엔진에 같은 인터페이스로 연결
   (명령 호출 + 선택 변화로 눌림 상태 갱신). TinyMCE 는 menubar·toolbar·statusbar 끄고 필요한 플러그인만, 자산은 로컬
   번들(오프라인), `license_key` 요구 여부는 TinyMCE 문서 원문으로 확인해 보고.
2. **이미지 붙여넣기 훅**: 붙여넣은 이미지를 엔진의 이미지 노드로 넣되 `src` 는 로컬 미리보기(blob URL)이고 노드에 앱
   내부 ID 속성. "저장" 버튼이 HTML 을 꺼낼 때 그 ID 를 `cid:` 로 바꾸고 파트 목록을 만드는 변환 함수(엔진 무관 순수
   함수)를 둔다. 실제 JMAP 업로드는 하지 않는다 — 변환 결과(HTML + 파트 목록)를 화면에 출력.
3. **다시 열기 흉내**: 같은 인스턴스에 다시 넣는 데서 끝내지 않는다 — **에디터 인스턴스와 만든 `blob:` URL 을 모두
   폐기**한 뒤, 저장한 HTML 과 시험 이미지 바이트(파트 목록에서)만으로 **새 인스턴스**를 열어 `cid:` → 새 미리보기로
   복원한다. 메모리에 남은 미리보기 덕분에 통과하는 일을 막기 위해서다. 왕복 뒤 이미지·서식이 남는지.
   실제 JMAP 저장·발송·수신 화면 확인은 이 시험에서 빼고 리치 텍스트 구현 단계에서 한다.
4. **측정 시나리오**(두 엔진 모두, 같은 순서 — 결과는 표):
   ```txt
   a  한글 IME: 본문에 한글 문장 입력 → 조합 중 Enter·Backspace·툴바 클릭(굵게) → 글자 깨짐·중복·커서 튐 여부
   b  한글 문장 중간에 스크린샷 붙여넣기 → 이미지 삭제 → 실행 취소 → 다시 삭제·다시 실행
   c  저장 변환 → 다시 열기(지시 3) → 이미지·굵게·목록·링크가 그대로인지
   d  메일 HTML 왕복: admin Inbox 테스트 메일(Google Calendar·공공데이터포털)의 HTML 일부를 넣었을 때 무엇이 사라지는지
      (참고용 — 답장 인용은 에디터 밖이라 결정 기준 아님)
   e  좁은 창(400px)·터치 에뮬레이션: 선택 후 툴바 눌러도 선택이 유지되는지
   f  오프라인: Tauri dev 창에서 네트워크 없이 둘 다 열리는지(외부 요청 0 — CDP Network)
   g  번들 증가량: 각 엔진을 넣었을 때 Angular 빌드 산출물 크기 차이
   ```
5. **보고서**: `docs/REPORT-MAIL-EDITOR-SPIKE.md` 에 표·스크린샷 경로·채택 권고·근거. 채택 엔진을 쓸 때 필요한 확장 목록,
   알려진 문제, 라이선스 표기(TinyMCE 면 GPL 고지 위치).

## 하지 않는 것

제품 작성 창 통합, JMAP 업로드·초안 저장, HTML 소스 모드, 표·마크다운, 답장 인용 영역, 의존성의 제품 빌드 포함.

## 산출물과 커밋

시험 코드와 시험용 의존성은 커밋하지 않는다(소유자가 결과를 보고 채택을 정한 뒤 리치 텍스트 브리프에서 정식으로 넣는다).
커밋 대상은 보고서 하나 — 그것도 사용자 승인 뒤.
