# Design: Client GUI Internationalization

2026-11-19. 구현 전 설계 방향 기록.

## 상태와 범위

클라이언트 GUI의 다국어 지원을 제품 요구사항으로 둔다. 이 문서는 방향만 기록하며
번역 라이브러리 설치·문자열 추출·번역·설정 저장 구현은 포함하지 않는다.
Mail·Contacts·ActivityPub의 대표 사용 흐름을 먼저 연결하고, 본격 GUI 설계 전에
i18n 구현 방식을 선택한다. [제품 UI 착수 기준](PLAN-JMAP-MAIL.md)을 함께 따른다.

## 언어 전환

앱 설정에서 언어를 선택하면 실행 중인 GUI에 반영하는 런타임 번역을 목표로 한다.
언어 변경 때문에 Tauri 프로세스 재시작을 요구하지 않는다. 재로딩 필요 여부와
편집 중 상태 보존은 라이브러리 선정 시 검증한다.

WordPress의 서버 측 번역처럼 다음 요청에서 새 HTML을 만드는 방식과,
클라이언트에서 번역 리소스를 교체하는 방식을 구분한다. PHP/Rust 언어 차이 때문에
번역을 Rust로 옮기는 것은 아니다.

## 책임 경계

| 영역 | 책임 |
|---|---|
| Angular | 메뉴·버튼·상태·사용자 안내 번역, 현재 언어 적용, 날짜·숫자 표시 |
| Rust / Tauri | 추후 선택한 방식에 따른 언어 설정 저장·OS 언어 전달, 구조화된 오류 정보 |
| 프로토콜 코어 | 로캘과 무관한 데이터·식별자·상태 처리. 번역된 문자열을 API 계약으로 사용하지 않음 |

Rust 오류는 코드와 매개변수로 식별할 수 있도록 하고 Angular가 사용자 설명을 번역한다.
서버 오류 원문과 진단 정보는 보존한다. 알 수 없는 오류도 표시할 수 있어야 하며,
자격증명·민감한 응답을 번역 매개변수나 로그에 무분별하게 넣지 않는다.
기존 오류 모델의 변경은 별도 구현 범위이며 이 문서가 이미 구현됐음을 뜻하지 않는다.

## 문자열과 콘텐츠

- UI 문구는 번역 리소스로 관리하고, 문맥을 식별할 수 있는 키/설명을 사용한다.
- 문장 조각을 이어 붙이지 않는다. 변수·복수형을 포함한 문장 단위로 번역한다.
- 버튼뿐 아니라 접근성 이름·툴팁·유효성 검사·로딩·빈 상태·오류도 포함한다.
- 날짜·시간·숫자 표시는 사용자 로캘에 맞춘다. 저장값·프로토콜 직렬화는 바꾸지 않는다.
- 메일 본문·연락처 이름·Actor 문서 등 사용자/서버 콘텐츠는 UI 언어로 자동 번역하지 않는다.
- URI·객체 ID·JMAP 메서드명·JSON 속성명 등 프로토콜 식별자를 번역하지 않는다.
- UI 언어, 콘텐츠 언어, 시간대는 서로 다른 설정으로 취급한다.

## 구현 선택: 미결

### 초기 폰트 자산

GUI에는 테마의 Roboto Flex와 Material Symbols Outlined만 로컬 자산으로 번들한다.
각 디렉터리의 라이선스와 source.txt를 함께 보존한다. WordPress 테마나 플러그인이
설치돼 있거나 외부 폰트 CDN에 연결돼 있어야 한다는 런타임 의존성은 만들지 않는다.
Roboto Serif·Roboto Mono·한국어 provider 폰트는 현재 번들하지 않는다.
지원하지 않는 문자는 시스템 fallback을 사용하며, 한국어 UI 번역과 한국어 폰트
동봉은 별개의 결정이다. 아이콘은 mat-icon의 fontSet으로 로컬 클래스를 지정할 수 있다.

### 번역 도구

Angular 공식 [i18n](https://angular.dev/guide/i18n)의 `@angular/localize`와
[언어별 빌드 흐름](https://angular.dev/guide/i18n/merge)을 기준점으로 검토한다.
공식 방식이라는 이유만으로 언어별 실행 파일을 배포하거나, 런타임 전환이
불가능하다고 단정하지 않는다. 런타임 번역 라이브러리와 다음 기준으로 비교한다.

- 재시작 없는 전환, 편집 중 데이터·탐색 상태 유지
- 오프라인 번역 리소스 패키징과 누락 번역 fallback
- 문자열 추출·문맥·변수·복수형 지원 및 유지보수 상태
- Angular Material 구성요소의 접근성 문구·paginator 등 별도 로캘 제공 경로
- 초기 OS 언어 선택과 사용자 지정 우선순위

라이브러리·번역 파일 형식·기본 언어·초기 지원 언어·설정 저장 위치는 아직 확정하지 않는다.
자체 범용 번역 엔진을 먼저 만들지 않는다.

## 구현 시 확인할 기준

언어 전환 후 화면·대화상자·Material 구성요소가 함께 갱신되고, 입력 중인 메일이나
연락처 편집 내용이 유지돼야 한다. 번역 누락·지원하지 않는 OS 언어·오프라인 시작을
검증한다. 긴 번역, 복수형, 날짜·숫자, 접근성 이름, 작은 화면의 잘림도 확인한다.
이 항목들은 향후 완료 기준이며 현재 자동 테스트로 강제되는 규칙은 아니다.
