Omphalos is an Axismundi child theme kept as a laboratory for Material Design 3
layout work.

== Description ==

Omphalos exists to try Material Design 3's layout and scaffold guidance against
real WordPress block templates, in a place where breaking things costs nothing.

It contributes no design language of its own. Colour roles, the type scale,
corner shape, motion, elevation, state layers, the focus ring, every core block
style, the block style variations and the bundled fonts all come from the
Axismundi parent theme. This theme carries composition only.

It is not intended as a general-purpose theme.

== Installation ==

1. Install and activate the Axismundi parent theme.
2. Upload and activate Omphalos as a child theme.
3. Open Appearance > Editor to customize templates and global styles.

== Changelog ==

= 0.2.0 =
* Re-point the theme from Twenty Twenty-Five to Axismundi as its parent.
* Remove the token layers, core block styles, block style variations, bundled
  fonts and icons, and the scheme application layer. Every one of them is now
  the parent's, and the parent addresses its own assets in a way that keeps
  resolving to the parent while a child is active.
* Remove the VQA specimen patterns, their seed scripts and their demo media,
  along with the migration route notes for the Twenty Twenty-Five pilot. That
  pilot is finished; its record is in the repository history.
* Narrow the theme to composition: templates, template parts and patterns.

Earlier releases described a Twenty Twenty-Five child theme and are listed in
the repository history.
