# Axismundi Specification

이 디렉터리는 canonical schema의 human-readable companion specification을 둔다. JSON
Schema는 shape를 검증하고 matching specification은 meaning, resolution rule, compatibility
requirement를 정의한다.

## 구조

```text
specs/
  style/
    <major>.md
  component/
    <major>.md
```

이 디렉터리 setup은 specification 내용을 정의하지 않는다.

현재 GitHub Pages에는 schema JSON만 배포한다. specification publication은 해당 document
surface가 실제로 필요해질 때 별도 결정한다.
